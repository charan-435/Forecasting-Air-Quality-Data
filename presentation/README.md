# Presentation files

| Location | Purpose |
|---|---|
| main.tex, segments/ | Current Beamer source, split into talk sections. |
| main.pdf | Compiled current deck. |
| images/ | Deck figures; published-paper images are labelled reference material. |
| webapp/ | Earlier static recorded-result viewer. |

Compile from this folder, for example with `latexmk -pdf main.tex`. Refresh figures from the repository root using the root README. The current React app lives in lab/, outside this folder.
